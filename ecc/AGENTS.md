# ECC content preferences

- Do not add introductory descriptions, description boxes, or topic summaries unless the user explicitly asks.
- Do not add or display source links or source attribution unless the user explicitly asks.
- Do not add or display last-reviewed dates unless the user explicitly asks.
- Preserve actual reference information, definitions, and quiz explanations; these are study content, not introductory descriptions.
- Do not add a footer label or study-aid disclaimer unless the user explicitly asks.

- Do not display general-reference, department-approval, or “confirm with your ECC” labels or messages. The user supplies content from their ECC; do not add these notices in future changes.

## Mobile-first layout

- ECC is primarily used on mobile. Prioritize readable, touch-friendly mobile layouts while keeping desktop polished.
- Topic action buttons should fill the available content row: use equal-width buttons when paired and a full-width button when alone. Preserve the centered reference-column width.
- All ECC pages must share the same centered desktop container width: use the common `main` layout (780px maximum, including padding), with no separate Library, topic, or Cards width overrides. Mobile remains full-width within consistent page padding.

- Keep Library topics in one list without category headings, and omit category labels above topic titles, until the user asks to restore categories.
- Use the shared page heading spacing on every view: no bottom margin on the title itself, with a consistent 16px gap below the heading block.
