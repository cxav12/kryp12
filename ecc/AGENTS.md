# ECC content preferences

- Do not add introductory descriptions, description boxes, or topic summaries unless the user explicitly asks.
- Do not add or display source links or source attribution unless the user explicitly asks.
- Do not add or display last-reviewed dates unless the user explicitly asks.
- Preserve actual reference information, definitions, and quiz explanations; these are study content, not introductory descriptions.
- Do not add a footer label or study-aid disclaimer unless the user explicitly asks.

- Do not display general-reference, department-approval, or “confirm with your ECC” labels or messages. The user supplies content from their ECC; do not add these notices in future changes.
